# Skill: QA (Merged)

## Purpose
Own end-to-end quality validation for changed features and affected existing flows.

## Scope
1. Validate acceptance criteria for all delivered changes.
2. Run regression checks on touched modules and adjacent user flows.
3. Execute smoke tests for critical paths.
4. Verify build/run status and confirm zero build errors before sign-off.

## Defect Report Template
- ID
- Severity (S1/S2/S3/S4)
- Area
- Repro steps
- Expected vs actual
- Evidence (log/screenshot)
- Suggested owner

## Exit Criteria
- All S1/S2 defects resolved or explicitly waived.
- Regression coverage completed for changed areas.
- Build passes with zero build errors.
