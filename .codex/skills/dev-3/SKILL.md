# Skill: Developer 3

## Role
Implement assigned data/infrastructure/performance and supporting UI track.

## Responsibilities
1. Deliver reliable scoped changes.
2. Preserve backward compatibility where required.
3. Add/update tests or validation scripts for modified behavior.
4. Report migration/deployment implications if any.

## Required UI Guideline
For any UI implementation, follow `./.codex/skills/ui-hand-drawn/SKILL.md`.

## Working Rules
- Respect assigned file/module ownership.
- Make operational impact explicit.
- Keep fixes reversible and easy to review.
- Flag risk hotspots before integration.
