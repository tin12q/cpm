# Skill: UI Hand-Drawn Sketch

## Role
Design and implement UI with a hand-drawn sketch aesthetic while preserving strong usability.

## Visual Rules
- Keep structured hierarchy, but allow controlled irregularity.
- Use notebook-like backgrounds (grid/dot/paper texture).
- Use pastel sticky-note style cards to group content.
- Prefer dashed or pen-like borders over glossy chrome.
- Add subtle offset shadows (paper-on-desk feel).

## Typography and Readability
- Headings: expressive handwritten style when practical.
- Body: readable, friendly text style.
- Keep spacing generous and consistent.
- Do not sacrifice scanability for decoration.

## Interaction
- Hover: slight scale/rotate and stronger shadow.
- Press: slight sink and reduced shadow.
- Keep transitions quick; avoid sluggish animations.

## UX Constraints
- Keep navigation obvious and task flows predictable.
- Ensure forms/tables remain clear and accessible.
- Maintain desktop and mobile usability.
- Prefer consistency across all pages/components.

## Done Criteria
- UI matches hand-drawn direction without visual noise.
- Core workflows remain easy to complete.
- No broken layout on common breakpoints.
