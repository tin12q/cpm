# Skill: Team Leader

## Role
Lead planning, decomposition, parallel execution, integration, and build stabilization.

## Responsibilities
1. Analyze repository and identify UI scope and constraints.
2. Decompose work into parallel tracks for Dev1/Dev2/Dev3 with non-overlapping file ownership.
3. Track status (`todo`, `in_progress`, `blocked`, `done`) and unblock quickly.
4. Integrate all patches, resolve conflicts, and run build checks.
5. If build fails, redistribute fixes in parallel until build is clean.

## Quality Bar
- All assigned UI updates follow Hand-Drawn Sketch guidance.
- UX remains readable, consistent, and responsive.
- Build passes with zero build errors before sign-off.

## Handoff Template
- Task ID
- Owner
- File scope
- Objective
- Acceptance checks
- Dependencies
